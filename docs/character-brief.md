# 经典 QQ 企鹅角色方案

## 当前决定

本地原型采用经典 QQ 企鹅的造型方向，不再设计原创替代角色。角色会根据参考资料从零进行像素重绘，不裁剪参考图，也不复用参考图中的像素。目标是还原早期桌面 QQ 宠物的圆润比例、低细节 2D 图像和陪伴感，并将其动作映射到 Codex 宠物状态。

## 本地素材

经典形象及其像素重绘、衍生动画属于第三方知识产权素材，只保存在 `.local-assets/`，该目录已被 Git 忽略。公开仓库不分发这些文件，开发者需要自行提供有权使用的素材。

## Codex 状态动作

| 状态 | 动作语言 |
| --- | --- |
| idle | 呼吸、眨眼、轻微左右晃动 |
| running-right | 面向右侧的小步移动 |
| running-left | 面向左侧的小步移动 |
| waving | 抬起翅膀或手势问候 |
| jumping | 下蹲、起跳、落地、恢复 |
| failed | 短暂泄气或难过后恢复 |
| waiting | 前倾并等待用户确认 |
| running | 专注工作，不做位移跑步 |
| review | 歪头或眯眼检查 |

Codex Pets V2 还包含两行共 16 个视线方向，用眼睛跟随指针位置；中性正面姿势同时写入官方校验器要求的 QA 格。

## 像素标准

- 清除色键残留后只保留最大主体连通区域。
- 先缩小到 `80 × 77` 逻辑像素并压缩到约 24 色，再以最近邻放大到 `160 × 154`。
- 每帧使用 `192 × 208` 单元格，脚底基线固定在 `y = 188`。
- 平移、形变和镜像都使用整数像素，避免模糊和半透明边缘。

## 发布边界

- 公共代码仓库只提交程序、动画规范、构建工具和占位素材。
- 经典 QQ 企鹅参考图、像素重绘和衍生动画不会提交到公共仓库。
- 对外发布包含经典形象的安装包前，需要确认已获得相应权利人的许可。
