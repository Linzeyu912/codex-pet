# 红围巾企鹅 · 固定角色设定

## 外形

怀念 QQ 农场的经典黑白企鹅，圆润黑色头身、白眼与白腹部、橙色嘴脚、红围巾。保持同一头径、身长、体量、镜头距离和像素风格。

## 围巾是硬约束

- 围巾只有一处短下垂，固定在企鹅自身左侧；正面看位于观众右侧。
- 向左走时自身左侧朝向观众，必须看见同一条下垂尾端；向右走和背面只显示围巾圈，尾端被身体遮住。
- 挥手与坐姿正面仍只有一个尾端；躺姿按胸口朝向遮挡。
- 不通过镜像复制来制造另一条围巾尾端。

参考：[QQ 企鹅设计稿报道](https://www.cnbeta.com.tw/articles/tech/1416459.htm)、[QQ 形象多视图检索结果来源](https://www.sohu.com/a/824042737_121124374)。本项目以用户明确的单一固定侧尾端及随转身遮挡的设定为准。

## 动画尺度

整张 4×4 姿态表只计算一次等比例缩放，不依据每帧面积或最长边重新拉伸。正面基准直接取第三行第二格，避免换生成批次时换脸。所有接地姿态在 192×208 格内对齐 y=187，跳跃使用精确平移。

站立姿态的源图细微差异会保留并在 QA 中报告；不得为了让包围盒数字相等而把侧躺或挥手重新放大。主图集和桌面姿态图的同一帧必须逐像素一致。

1. 四帧左侧步态。

3. 挥手、正面、背面过渡、背面。
4. 倾倒过渡、侧躺、仰躺、坐起。
