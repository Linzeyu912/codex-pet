# 角色方案与发布边界

## 公共原创角色：Aurora Penguin

公共版本默认使用项目原创 Aurora 企鹅：靛蓝身体、象牙白腹部、琥珀色嘴脚、青绿色不对称探索者短披肩和金色星点徽记。它采用清晰的小尺寸像素轮廓，避免红围巾、现有知名企鹅角色的脸部比例、品牌标志和文字。

公开基础站姿与专用挥手姿势分别保存在 `public/aurora-penguin.png` 和 `public/aurora-penguin-wave.png`。构建器负责限色、最近邻缩放、动作编排和严格图集检查；公开图集的所有站立动作统一为 `170px` 可见高度，悬停跳跃必须是站姿的精确垂直平移，透明像素 RGB 必须归零且不得保留半透明色边。视线循环移动眼内青色高光并以语义质心检查方向，不以整只角色平移伪装视线。

Aurora 的公开动作以低干扰、友好陪伴为目标：呼吸与眨眼保持脚底稳定，挥手使用连接肩部的专用抬翅姿势，左右步态共享节奏但方向明确。它是公共发行、干净克隆和首次安装的完整默认体验，不再作为占位资源处理。

## 本地经典 QQ 企鹅

## 定位

本地原型直接采用经典 QQ 企鹅的造型方向，不设计成另一个原创角色。动画以经典黑白圆润身体、橙色嘴脚、红围巾和亲近调皮的气质为统一识别点，并从参考形象重新进行像素化绘制，不裁剪原图或直接复用原图像素。

这仍是经典角色的衍生表达，不会因为“重新像素绘制”而变成项目自有 IP。相关参考、重绘和动画只保存在被 Git 忽略的 `.local-assets/` 中，限有权进行的个人本地实验。

## 一致性基准

所有角度和动作必须看起来是同一只企鹅：

- 头身比例、腹部轮廓、嘴和脚的橙色、围巾红色及尾端位置保持稳定。
- 正面、左右侧面、背面和躺姿共用同一体量；转身时只改变透视与遮挡，不突然变高、变瘦或换脸。
- 围巾是方向提示：侧身时随身体转向，背面仍能看到合理绕颈关系，躺下时服从重力而不跳位。
- 左右步态可共享节奏，但最终帧必须有明确方向语义；不得把正面企鹅仅平移来伪装侧身。
- 每个动作按“预备 → 主动作 → 缓冲/恢复”组织，首尾姿势能自然接回 idle。

## Codex V2 动作

| 状态 | 动作语言 |
| --- | --- |
| `idle` | 低干扰呼吸与眨眼，身体和脚底稳定 |
| `running-right` | 真正右侧身，交替抬脚并摆动翅膀 |
| `running-left` | 真正左侧身，交替抬脚并摆动翅膀 |
| `waving` | 从自然站姿抬翅问候，再顺势收回 |
| `jumping` | 下蹲蓄力、离地、顶点、下降、落地缓冲 |
| `failed` | 失去平衡、侧倒/趴下，并留下可停留的躺倒帧 |
| `waiting` | 收拢双翅、眨眼和轻呼吸，表现耐心而非僵住 |
| `running` | 原地忙碌处理，动作持续但不表现成水平奔跑 |
| `review` | 身体稳定，以视线与眉眼小动作表现仔细检查 |
| `look` | 16 个方向按每格 `22.5°` 顺时针平滑旋转视线 |

拖拽时按水平移动方向使用左右侧身步态；松手或桌面巡游转向时等当前循环收口再切换，避免动作中段突然闪回正面。

## 桌面专用调皮动作

本地 `4 × 4` 姿态表是 V2 之外的桌面扩展：

| 行 | 4 个关键姿态 |
| ---: | --- |
| 1 | 左侧身步态循环 |
| 2 | 右侧身步态循环 |
| 3 | 回头、背面、背身调皮和转回过渡 |
| 4 | 下蹲/侧倒、侧躺、仰躺/翻身和坐起恢复 |

这些姿态编排为：

- `mischief`：回头确认 → 背过身做小动作 → 再回头 → 正面站好。
- `lying`：下蹲转身 → 侧躺 → 短暂停留/翻到背面 → 坐起 → 回到正面。
- `rolling`：侧倒 → 翻身 → 借力坐起 → 恢复站姿。

动作可以调皮，但不得靠随机切换角度制造“热闹”；背面、侧面和躺姿之间必须有中间关键帧和连续重心轨迹。

## 像素与装配标准

- Codex V2 与桌面扩展都使用 `192 × 208` 单元格；V2 总图为 `1536 × 2288`，桌面姿态图为 `768 × 832`。
- 主体使用统一尺度、水平中心和 `y = 188` 脚底/接触基线；跳跃、躺倒等动作只在语义需要时离开站立基线。
- 本地基础生成流程可先缩至约 `80 × 77` 逻辑像素、限色，再用最近邻放大；禁止双线性缩放造成模糊边缘。
- 透明背景必须清理色键残留、孤立碎片和低透明噪点；完全透明像素的 RGB 归零。
- 整行动作使用同一角色基准和同一生成批次，避免把不同画风、光源、轮廓或比例的单帧直接拼接。
- 连续性审查覆盖脚底、质心、轮廓面积、相邻帧重叠、首尾闭环和方向语义；修复后整行重新装配与复检。
