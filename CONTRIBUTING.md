# Contributing

Run `pnpm install --frozen-lockfile`, `pnpm assets:prepare`, and `pnpm verify` before requesting review. Keep package.json, Tauri and Cargo versions synchronized.

Both the desktop and Codex pet must use the red-scarf character. Follow [the character specification](docs/character-brief.md), especially the single fixed-side scarf tab and its directional occlusion and shared camera scale. Preserve installation backups, conflict checks and atomic writes.

Code contributions use MIT. Character artwork is excluded from MIT; see [ASSET-LICENSES.md](ASSET-LICENSES.md). 如有侵权，请联系删除。
